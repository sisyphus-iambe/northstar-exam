Northstar

A trust checkpoint for AI-generated artifacts.

Submit an AI-generated statistical implementation, get a four-layer verdict: calibration / cross-reference / boundary coverage / degenerate inputs. Correct → ACCEPT, wrong → REJECT. No LLM self-evaluation anywhere — verdicts come from deterministic programmatic checks against independent references.

The four-layer exam

LayerWhat it checks
L1 · calibrationH0 simulation sampling: p-values uniform on the continuous region, conservative on the discrete region. NaN scores nothing.
L2 · cross-referenceCandidate p-values must match two independent reference implementations to 1e-6 (references self-check known answers + agree with each other first, or the run aborts honestly).
L3 · coverageBoundary generalization: 5 shapes × 76 inputs — tiny samples, large samples, strongly skewed margins, zero cells, mixed medium samples.
L4 · degenerate inputs9 malformed-input classes (NaN / Inf / zero table / single row / single column / string / empty). On the 7 classes where the reference itself fails honestly, a candidate that silently returns a finite p-value is hallucinated filling = FAIL.

Measured on real LLM output

Internal acceptance evaluations — the exam-setting kit is open so every number below is re-derivable from this repository.

  • 14.8% of 54 hand-written LLM statistical implementations violated the direction-complementary identity (p_less(x,y) vs p_greater(y,x)); spot checks confirmed every one was a real bug.
  • 492/500 direction-flip variants rejected by the invariant examiner; 0/500 false positives on correct implementations.
  • 5.9% pass rate: of 17 fresh LLM-written chi-square implementations, only 1 passed all four layers. "Computes right but lies" is the norm, not the edge case.
  • 60/60 dirty samples detected on 402 real robot demonstration trajectories (NaN / out-of-range / jumps), 0/30 false positives.
  • 0/20 type-confused samples caught by a popular open-source robot-data tooling stack — outright-corrupted data treated as normal; it crashed on 20/20. These bug classes ship in the wild.

Everything is open

  • Compiled exams (four-layer + L1-only, pearson and wilcoxon families) in exams/ — tamper-evident via spec_md5 / content_md5.
  • Recompile any exam from its spec and diff the fingerprints (spsl.compile_l1/l2/l3/l4, compile_inv).
  • Invariant exams: reference-free identity checks at 500-sample resolution.
  • MCP gateway: run exams as an MCP stdio server (statistical / conclusion_anchor / demo_data / state_estimator / invariant).
  • Self-proof: calibrator/run_experiment.py re-derives the acceptance numbers from first principles (sensitivity 1.000, false-kill 0.020).
  • Determinism: same environment → byte-identical verdicts; 5 exam pairs verified byte-identical (ci/batch_determinism.py, 27 tests).
