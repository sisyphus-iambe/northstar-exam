# 工具形态 MVP: 验证器质检 CLI (verifytool)

> 命题: 把校准层四层考卷封装成可交付工具 — 输入一个统计验证器实现, 输出四层考卷校准报告(能力地图 + 盲点清单)
> 2026-08-07 定稿. 来源: 状态文件 §14 工具化路径第 3 步"工具形态定型" + 用户拍板 MVP CLI
> 原则: **纯组装, 零新发明** — 每个零件标注已有出处; 不改 calibrator/ programs/ 任何现有文件
> 方法: 主终端写规格, 实现委托 sub-agent, 结果主终端独立验证

## 1. 输入输出契约

**输入**: 一个 .py 文件, 暴露 `chi2_pvalue(observed) -> float` (任意 r×c 计数表, 边缘全正) — 与被测接口契约一致 (experiments/qualcheck_realworld/SPEC 第 2 节同款)

**输出**:
- HTML 报告 (默认输出到 cwd/`verifytool_report_<验证器名>.html`): 四层考卷判定 + 能力地图 + 盲点清单
- JSON 结果 (同名 .json): 结构化落盘, md5 双字段 (payload_md5 = json.dumps(payload, sort_keys=True, ensure_ascii=False); self_md5 = json.dumps(去 self_md5, indent=2, 无 sort_keys, ensure_ascii=False) — bootstrap_monotone 同款算法)

## 2. 运行时构成 (全部毫秒-秒级, 无慢项)

1. **动态加载**: importlib.util 加载用户 .py, 查找 `chi2_pvalue`; 不存在/不可调用 → 友好报错退出 (列出找到的函数清单, 提示契约)
2. **四层考卷**: 调 `calibrator/calibrate.py` 的 `calibrate(func, seed)` — L1 随机 4000 表 / L2-L4 固定考卷
   - 默认 3 runs (seeds = 20260807/20260808/20260809, `--runs` 可改); L1 判定 = 多 run 汇总 (同 run_experiment.py 100 runs 协议, 按 run 数归一)
3. **能力地图**: 9 模板 × L2-L4 对拍 (固定考卷, 毫秒级) — chi2_rxc / fisher / ratio / replicate / slope / strat_bidir / stratified / trend / barnard
   - 对拍参照 = `calibrator/reference.py` (手写 gammq + ref_scipy, 自检 1e-9)
   - 每模板: 与参照最大偏差, 是否过 1e-6 容差, PASS/FAIL
4. **盲点清单** (自动生成, 零 LLM):
   - L4 命中: 9 类畸形输入中哪些返回了有限值 (幻觉填补) → 列具体输入形态
   - L2/L3 对拍 FAIL 的表型: 偏差最大的 5 张表 (n / 形状 / 偏差值)
   - 覆盖边界: 固定考卷无法覆盖的形状类别如实列出 (工具边界, 同实验 05 诚实标注)

## 3. HTML 报告结构 (复用实验 05 报告样式)

1. 头部: 被考验证器文件 + 运行时间 + 版本
2. 四层判定表 (L1-L4 × PASS/FAIL/REJECT + 关键数字)
3. 能力地图: 9 模板 × L2-L4 判定矩阵 (颜色标注) + 参照基准
4. 盲点清单: 分层列出 (L4 幻觉填补 / 对拍偏差 / 覆盖边界)
5. 背景与诚实标注: 工具校准层自己的校准记录 (合成自证灵敏度 1.000/误杀 0.020 + 实验 05 真实演示) + 工具边界 (只考实现正确性不考方法选择 / 频率学派框架等)

纯静态 HTML, 无外部 URL, 可独立打开。

## 4. 新代码 (全部新文件, 零改动现有)

## 5. 自测与验收 (演示路径)

- 自测输入: `experiments/qualcheck_realworld/programs_real/` 的三个程序:
  - `scipy_direct.py` → 预期报告如实显示 L4 REJECT (scipy 退化表静默 p=1.0) 或如实记录
  - `wrong_fillna.py` → L4 REJECT (静默填补)
  - `wrong_dof.py` → L2/L3 REJECT
- **与实验 05 判定表对照**: 层定位一致 = 复用正确性证明 (实验 05 判定表出处: experiments/qualcheck_realworld/results.json + 状态文件 §17)
- 主终端验收: ①md5 双字段独立复算 ②3 个演示与实验 05 判定对照 ③HTML 三部分齐全 ④calibrator/programs 零改动 (git status) ⑤确定性 (重跑一致)

## 6. 约束与护栏

- 不改 calibrator/ programs/ 任何现有文件; template_exam/ 只读
- 不联网, 零 pip 安装
- 单验证器运行 < 2 分钟 (L1 3 runs × 4000 表 ≈ 秒级; 若用户验证器本身慢, 如实报告耗时并给超时提示)
- 内存 < 1GB
- 写文件遇 post_write_hook 报错 (指向不存在的 hook 文件): 忽略, 写入已成功

## 7. 诚实标注 (写进 README)

- MVP = 工具形态第一版, 覆盖"验证器质检"主链路; 9 模板 L1 慢速考卷 (barnard 类) 不在单次运行内 (那是模板库自校准档案, 工具背景基准), 如实说明
- 工具不评判方法选择 (用卡方还是费雪), 只考实现正确性
- 单验证器报告 = 一次采样快照, 非统计保证 (与合成自证口径一致)
